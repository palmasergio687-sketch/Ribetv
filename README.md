# WORLD TV PARAGUAY

Proyecto inicial Flutter para Android móvil y Android TV. Incluye catálogo de accesos a plataformas oficiales, filtros por país/categoría y favoritos.

## Generar APK desde un teléfono (sin PC)

1. Crea una cuenta gratuita en https://github.com/ si todavía no tienes.
2. En GitHub, crea un repositorio nuevo llamado `world-tv-paraguay`.
3. Sube el contenido completo de este ZIP al repositorio (incluida la carpeta oculta `.github/workflows`).
4. Abre la pestaña **Actions** del repositorio.
5. Selecciona **Build Android APK** y pulsa **Run workflow**. También se ejecuta al subir cambios a `main`.
6. Cuando termine correctamente, abre la ejecución y descarga el artefacto `world-tv-paraguay-apk`. Dentro estará `app-release.apk`.

## Importante
- Este repositorio incluye accesos a páginas/plataformas oficiales; no incluye URLs directas de streaming ni credenciales premium.
- Las plataformas de pago deben abrirse con la cuenta/suscripción propia del usuario.
- El APK resultante es una primera versión de catálogo; no se debe presentar como un reproductor IPTV con señales ya conectadas.
- El workflow genera el proyecto Android de Flutter durante la compilación.
